# Testing — Employee ID Validator

## 1. Strategy

| Layer | What is tested | Where |
|---|---|---|
| Language / Layer 1 | Σ membership, look-alike Unicode, whole-string check, empty input | `tests/core/test_language.py`, `test_simulator.py` |
| RE → NFA | Thompson structure, real ε-closure, nondeterminism | `tests/core/test_nfa_pipeline.py` |
| NFA → DFA | subset steps, dead state, agreement | `tests/core/test_nfa_pipeline.py` |
| Minimization | rounds, no-merge proof, real merging on a redundant DFA, idempotence | `tests/core/test_minimization.py` |
| Equivalence | exact product-automaton proof, mutation detection, exhaustive ≤ 4, neighbourhood, random + Unicode | `tests/core/test_equivalence.py` |
| Simulator | Layer 1 vs Layer 2, expected-symbol messages, step-by-step ≡ one-shot for all three models | `tests/core/test_simulator.py` |
| Services | sessions, modes, computed metadata | `tests/services/test_services.py` |
| GUI (offscreen) | loading is paused, input never trimmed, diagram marks only visited states, all three models, batch, animation end-states, hover / click explanations, RE-segment bars, accessible names, keyboard focus, theme contrast | `tests/gui/` |
| Docs | embedded tables equal the code | `tests/test_docs.py` |

Run everything: `python -m pytest`  (GUI tests use `QT_QPA_PLATFORM=offscreen`, set automatically).
